# TutorLedger для Windows

Приложение для учёта учеников, занятий и оплат. Работает локально на Windows 10/11 x64.

Готовые версии размещаются в разделе **Releases** этого репозитория. Для первой установки скачайте файл `TutorLedger-<версия>-Setup.exe`. Python отдельно устанавливать не требуется.

Обновления доступны через настройки приложения, если установлен выпуск с подключённым интернет-каналом. Можно также установить новую версию поверх старой или выбрать `TutorLedger-<версия>-Update.zip` в настройках.

Рабочая база и резервные копии находятся в `%LOCALAPPDATA%\TutorLedger`. Обновление и удаление программы не удаляют эти данные.

Этот репозиторий содержит готовые установщики и сведения об обновлениях. Исходный код хранится отдельно в закрытом репозитории.
